## 💡 Why this exists

> [!TIP]
> Find and book appointments with the best doctors using advanced search and filtering.

**Background:** A modern, responsive Next.js web application designed to help patients search for healthcare professionals. It offers a robust client-side filtering system for specialties, consultation modes, and pricing, built with React and Tailwind CSS.


## ✨ Features

- **Smart Search & Autocomplete:** Interactive search bar that filters doctors by name, specialty, or clinic, offering real-time dropdown suggestions.
- **Advanced Search Filters:** Comprehensive client-side filtering system allowing users to refine lists by specialty checkboxes, consultation mode (Video/In-Clinic), and sorting by fees or experience.
- **Dynamic Avatar Generation:** Automatically generates custom fallback avatars with initials and deterministically assigned colors based on name hashing.
- **Responsive UI Architecture:** A polished, responsive design leveraging Tailwind CSS with dynamic dark mode support and custom utility animations.

## 🚀 Quick Start

> [!IMPORTANT]
> Ensure you have Node.js and npm installed on your system before proceeding with the environment setup.

### Prerequisites

| Requirement | Version | Notes |
|-------------|---------|-------|
| Node.js | `>= 18.x` | Required to execute the Next.js framework |
| npm | `>= 9.x` | Package manager for dependency resolution |

### Clone & Setup

```bash
git clone https://github.com/D4rk-Pho3nix/my-app.git
cd my-app
```

**Install**
```bash
npm install
```

**Build**
```bash
npm run build
```

**Run**
```bash
npm run dev
```

> [!NOTE] 
> The development server will spawn and bind to port `3000` by default.


## 📖 Usage

Launch the development server to access the booking interface. The main page automatically renders a list of doctors with functional search, filtering, and sorting out-of-the-box.

**Running the app locally in development mode:**
```bash
npm run dev
# Navigate to http://localhost:3000 in your browser
```
